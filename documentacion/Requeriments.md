# 1. Requirements - Descripción del Proyecto

##  Problema a Resolver
Se quiere sistematizar la administración académica de una institución mediante un software.  
El sistema permitirá gestionar de manera segura un sistema de roles, donde se podrá:
- Organizar el personal docente  
- Gestionar los alumnos  
- Permitir a los administradores visualizar y modificar toda la información

##  Funcionalidades Principales

##  Restricciones Técnicas

###  Plataformas y Entornos
- El sistema debe ser compatible con cualquier navegador web  

###  Infraestructura y Hardware
- El sistema debe poder ejecutarse en un servidor  
- El servidor deberá estar operativo 24/7  

### Lenguajes y Frameworks(viejo)
- Lenguaje: Java  
- Motor de plantillas: Mustache  
- Gestión y automatización: Maven  
- Base de datos: MySQL  
- ORM: JDBC
