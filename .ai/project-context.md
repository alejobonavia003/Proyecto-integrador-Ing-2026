# Proyecto

Sistema de Gestión Estudiantil.

## Objetivo

Administrar carreras, planes de estudio, materias,
correlatividades, usuarios, inscripciones y dashboards académicos.

## Stack

- Java
- SparkJava
- Mustache
- Maven
- Sqlite
- ActiveJDBC

## Roles

- Admin
- Alumno
- Profesor

## Metodología

- Kanban
- GitHub Issues
- Desarrollo iterativo
